# nimaid-noto-emoji

[Noto Color Emoji](https://github.com/googlefonts/noto-emoji) (OpenType-SVG flavour, SIL Open Font License 1.1) packaged for
[nimaid](https://pypi.org/project/nimaid/). Install with `pip install "nimaid[emoji]"`; nimaid picks it up automatically.

```python
import nimaid_emoji
nimaid_emoji.font_path()      # absolute path of NotoColorEmoji-Regular.ttf
```
